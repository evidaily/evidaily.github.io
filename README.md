# Evidence Daily / 今日可驗證

Daily verifiable data points with full evidence chains.

https://evidaily.github.io

## Principles
- One publicly verifiable data point per day
- Complete evidence chain (source, method, limitations)
- Fully reproducible by anyone
- No tracking, no login
- Bilingual (EN / 中文)
